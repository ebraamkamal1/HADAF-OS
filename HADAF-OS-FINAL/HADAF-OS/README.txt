HADAF OS — Static Edition
========================

READY TO UPLOAD
1. Extract the ZIP file.
2. Upload the contents of the HADAF-OS folder to your hosting public_html (or website root).
3. Open your domain. The entry file is index.html.

No database, PHP, Node.js, build process, or server configuration is required.

Features:
- Overview dashboard
- Projects and progress tracking
- Task board with status columns
- Departments
- Products and services
- CRM / clients
- Marketing campaigns
- Finance tracker
- Meetings and decisions
- Knowledge base
- Calendar
- Arabic / English interface
- Light / Dark theme
- Local JSON backup and restore

IMPORTANT DATA & SECURITY LIMITATIONS
This is a browser-local edition. Records are stored in LocalStorage on the current browser/device.
They do not sync across users or devices. Clearing browser data can erase the workspace.
Export a JSON backup regularly from Settings.
This edition has no real user accounts, server-side permissions, or confidential multi-user access.
Do not store passwords, payment details, or sensitive personal/financial data in it.
The Google Fonts import is optional; if unavailable, local system fonts are used.
